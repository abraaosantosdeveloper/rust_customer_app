## Features

The application is a complete local "CRUD" system. You can register a new customer, edit it, update it and delete as well.

- Create Customer
- Edit Customer Information
- Update Information
- Delete Information

## How to run

You need to have **Cargo** installed. If you don't have it, download the [Rust installer](https://rust-lang.org/tools/install/), run it and you are ready to go.

After installing Rust, just open the app folder on your terminal, and type: 

`cargo run`

### Dependencies

You will need to add the following dependencies by running `cargo add <dependency_name>`:

- clearscreen
